纯 Markdown 到底

丢一个链接进来，先抓正文或站点卡片，落成 收藏夹/ 里的一个 md；图标位置、大小、所属区域都写在 frontmatter。没有数据库，没有 sidecar，文件挪走画布就跟着变。

网页、应用、笔记同桌

从浏览器拖链接，从 Finder 拖 .app、文件夹或文件，从 vault 拖 Markdown 和 PDF。都是桌面上的图标：网页开浏览器，应用直接启动，笔记开标签页。

缩小是为了导航

区域名字始终是屏幕上的 12px；缩小时说明、摘要、标题依次让位给图标本身。一眼看全局，滚一下就回到细节。笔记正文里也能嵌一块同样的画布。

安装

Obsidian 桌面端（macOS / Windows）。用 BRAT 装，不用碰任何文件夹，之后还会自动更新。
